# 💰 Personal Finance Dashboard
My Personal Finance Dashboard is a desktop app built in C# using Windows Presentation Foundation (WPF) inside Visual Studio.

## 🎯 Project Goals
- build finance tracker that helps the user track income, expenses, and savings
- clean, modern, and professional in appearance
- practice UX / UI design principles
- display financial data visually (charts + summaries)

## Features 
- dashboard
- transactions
- analytics
- different settings

### 📊 Dashboard
- total balance summary
- monthly income vs expenses
- category breakdown chart
- recent transactions list
### 💸 Transactions
- add / edit / delete transactions
- categories (rent, food, travel, entertainment, transportation, etc.)
- date filtering
### 📈 Analytics
- pie chart for spending categories
- monthly trend line chart
### ⚙️ Settings
- dark / light toggle mode
- currency selection (optional)
