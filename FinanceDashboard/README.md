# Personal-Finance-Dashboard
a desktop application built in C# using Visual Studio that helps users track income, expenses, and savings through a clean, modern dashboard UI with charts and category-based visualization

---

## 🎯 Objectives
- build a finance tracker with a professional appearance
- practice UX / UI design principles
- use MVVM architecture
- display financial data visually
- store data locally (JSON / SQLite)
